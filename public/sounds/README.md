# Sound Files for Pomodoro Timer

## Available Sounds:
- beep.wav - Default beep sound
- bell.wav - Bell sound
- chime.wav - Chime sound  
- ding.wav - Ding sound
- notification.wav - Notification sound

## How to add custom sounds:
1. Add .wav, .mp3, or .ogg files to this folder
2. Update the soundOptions in Settings.jsx
3. Update the soundOptions in notifications.js

## Note:
For now, we'll use programmatically generated sounds via Web Audio API.
You can replace these with actual audio files by placing them in this folder.
